# Dashboard source and ownership manifest

The Platform dashboards in this pack are locally authored and generated by `scripts/generate-observability-dashboards.py`. Official CloudNativePG and Cilium dashboards are supplied by immutable dependencies or files in their pinned Helm charts. The Flux Cluster Stats dashboard is generated from an immutable upstream file, and the mixin-derived alert contract is validated against its pinned source by `scripts/generate-flux-mixin.py`. No dashboard is downloaded from a mutable URL at runtime; CI rejects generated-file drift and validates chart-owned dashboard contracts.

## Versioning policy

- The deployed Helm chart versions pin the exporter and application versions that define these metric contracts.
- Every dashboard query is syntax-checked and executed against the live Prometheus inventory during rollout.
- A dependency update that renames or removes a metric must update the generator and tests in the same pull request.
- Future imported dashboards or mixins must record an immutable release or commit, license, downloaded SHA-256, and local patch set in this file.
- Mutable `main`, Grafana.com `latest`, and runtime dashboard downloads are prohibited.

## Privacy policy

Dashboards must not embed private addresses, internal hostnames, credential names, account identifiers, or device labels. Variables and legends use labels emitted by monitored workloads at query time rather than infrastructure literals committed to Git.
